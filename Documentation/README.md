# Truzon Homes — CMS & Website Documentation

A practical guide for staff using the Truzon CMS to run truzonhomes.com. This isn't a developer manual — it's written for whoever is actually logging in day to day to add a property, publish a blog post, or check who filled out the contact form.

**Where to log in:** the CMS admin dashboard (ask whoever manages hosting for the current URL — it's `localhost:3001` in development). The public website itself (what visitors see) is a separate, connected site — you never edit it directly; everything on it comes from what you do in the CMS.
