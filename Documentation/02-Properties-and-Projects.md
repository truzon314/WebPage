# Properties & Projects

This is the CMS's **Projects** section in the sidebar — it manages every property listing shown on the public site's Projects page, homepage, and individual property pages.

## Creating a property

1. **Projects** → **+ New Property**.
2. Fill in the basics: Name, City, Location, Price (display text like "₹1.6 Cr"), Price (numeric — used only for sorting, not shown to visitors), Budget bracket, Spec A/B (e.g. "4 BHK" / "3500 Sq.Ft"), Area, Bed options.
3. Click **Create** — this takes you into the full property editor.

## Editing a property

Click any property in the list to open its editor. Fields include:

- **Description** — the long write-up shown on the property's page.
- **Amenities** — a repeatable list (name + optional photo each) — clubhouse, parking, security, etc. Use **+ Add Amenity** to add more.
- **Tag badge text** (e.g. "NEW LAUNCH", "EXCLUSIVE") and **Status badge text** (e.g. "Ready to Move") — the small colored labels shown on the property card.
- **Signature property** checkbox — flags it as a signature listing (used in some layouts, though the homepage's featured section now shows properties by priority order, below).
- **Featured image** — the main photo shown on cards and at the top of the property page.
- **Brochure PDF** — upload a PDF and visitors get a real **Download Brochure** button on the property page.
- **Linked Map Layout** — connects this property to an interactive site-layout map built in [Map Management](05-Map-Management.md), so its page shows the plot map.
- **Type / Categories** — check which type(s) this property is (Villas, Plots, etc.) — this drives the filter buttons on the public Projects page.

Click **Save Details** after making changes.

## Gallery

The right-hand panel on the property editor. **Add from Media Library** to bring in photos, then **drag to reorder** them — photos 1–4 become the interactive gallery thumbnails on the property's public page. Click **Save Gallery** separately from the main Save button.

## SEO

At the very bottom of the editor, the **SEO & Social Metadata** panel controls how this property looks when shared on WhatsApp/social media and in Google search results (meta title, description, keywords, social preview image). If you leave it blank, the site automatically falls back to the property's own name and featured photo — you don't have to fill this in for every listing.

## Publishing

New properties start as **Unpublished** (a gray dot next to the name at the top). Click **Publish** to make it visible on the live site, or **Unpublish** to pull it down without deleting it.

## Controlling display order (Priority)

Which properties show first on the homepage and at the top of the Projects page is controlled by **drag-and-drop** on the Projects list page itself — not a separate setting.

1. Go to **Projects**.
2. Each row has a small grip handle (⠿) on the left.
3. Drag rows into the order you want. The top row shows first everywhere on the public site.
4. It saves automatically as you drop — no separate save button.

This only works when there's no search filter active (clear the search box first if it's not responding to drags).

## Duplicating and deleting

- **Duplicate** (on a property's page) makes a copy named "*(Copy)*" — handy for near-identical listings.
- **Delete** moves a property to [Trash](13-Trash-and-Audit-Logs.md#trash), where it can be restored later. It doesn't disappear permanently until someone empties the trash.

## Property Types (the filter categories)

Above the property list, the **Property Types** panel lets you add/remove the type options shown as filter buttons on the public Projects page (currently Villas, Plots). Adding a new type here makes it available to assign on individual properties and appear as a new filter.
