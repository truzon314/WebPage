# Media Library

Every photo, PDF brochure, and video used anywhere on the site — properties, blog posts, pages, testimonials — lives here. Uploading once and reusing from the library (instead of re-uploading the same photo in five places) keeps things organized and saves storage.

## Uploading

Drag files onto the upload area, or click to browse. Accepted types: images, video, PDF, Word, Excel, SVG, and ZIP. Maximum size is **25MB for images** and **200MB for video** — larger files are rejected.

## Folders

Use **+ New Folder** to organize uploads (e.g. one folder per property, or "Brochures", "Team Photos", "Blog Images"). Drag files between folders to reorganize.

## Using media elsewhere

Anywhere you see an image field in the CMS (a property's featured image, a blog post's cover, a page block's photo), clicking it opens a picker into this same library — either pick an existing file or upload a new one on the spot without leaving what you were editing.

## Editing details

Click any file to open its details — you can set **alt text** (a short description used for accessibility and SEO; important for images) and see which content is currently using that file.

## Deleting

Deleted files go to [Trash](13-Trash-and-Audit-Logs.md#trash) like other content, so an accidental delete isn't permanent. Note: if a file is actively in use somewhere (a property's featured image, etc.), check the details drawer first — removing it will leave that spot blank on the live site.
