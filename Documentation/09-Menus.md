# Menus

Controls the actual navigation links shown in the site's header and footer. There's a **fixed set of 5 menus** — you can't create or delete a menu, only edit which links are in each one:

| Menu | Where it shows |
|---|---|
| Header Navigation | The main nav bar at the top of every page |
| Footer — Company | One of the footer's link columns |
| Footer — Properties | Another footer column |
| Footer — Resources | Another footer column |
| Footer — Legal | The small print links at the very bottom (Privacy Policy, Terms, etc.) |

## Editing a menu

1. **Menus** → click the one you want (e.g. "Header Navigation").
2. Each row is one link: a **Label** (what visitors read, e.g. "Projects"), and either a link to an internal **Page** (Home/About/Projects/Blog/Contact) or a custom **URL** for anything else (an external site, or a path like `/careers`).
3. External URLs have an **Open in new tab** option.
4. Links can be nested — a top-level item can have sub-links under it, for a dropdown-style submenu.
5. Drag items to reorder them — order here is the order they appear on the site.
6. Click **Save Menu** when done. Nothing changes on the live site until you save.

## A word of caution

This directly controls live site navigation — a typo'd URL or a removed link means visitors can't find that page anymore (even if the page itself still exists). Double-check a link before saving, especially on Header Navigation.
