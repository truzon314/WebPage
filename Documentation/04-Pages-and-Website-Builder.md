# Pages & Website Builder

**Pages** manages the content on five fixed pages of the public site: **Home**, **About**, **Projects**, **Blog**, and **Contact**. (Properties/blog *listings* themselves come from their own sections — this is about the surrounding page content, like the About page's story section or the homepage's hero banner.)

Unlike Blog Posts or Properties, you can't create or delete pages here — there's a fixed set of five, and you're editing what's *on* each one.

## The block builder

Open a page and you'll see two panels:

- **Blocks** (left) — the list of content sections currently on this page, in order. Drag to reorder them, or click **+ Add Block** to insert a new one.
- **Block editor** (main area) — click any block in the list to edit its content here.

## Block types available

| Block | Use for |
|---|---|
| Hero Banner | Full-width top banner with heading, subheading, and a button |
| Text | A paragraph of formatted text |
| Image | A single photo |
| Gallery | A grid of multiple photos |
| Video | An embedded video |
| Team | Staff/team member cards (photo, name, role) |
| Testimonials | Customer quote cards |
| FAQ | An expandable question/answer list |
| Accordion | Generic expandable sections |
| Features | Icon + text feature grid |
| Statistics | Big numbers (e.g. "500+ Happy Families") |
| Timeline | A step-by-step or milestone list |
| Pricing | Pricing/plan cards |
| CTA | A call-to-action banner with a button |
| Contact Form | An embedded enquiry form |
| Map | An embedded location map |
| Divider / Spacer | Visual spacing between other blocks — no content |

Each block type has its own editor with the fields relevant to it (a Hero Banner asks for heading/subheading/button/background image; a Team block lets you add repeatable member entries; and so on).

## Saving, publishing, and previewing

- Changes to a block save when you're done editing it — there's no separate "save the whole page" step for block content.
- **Preview** shows the page as visitors would see it before you commit to anything public-facing.
- **Schedule** and **Publish**/**Unpublish** work the same way as [Blog Posts](03-Blog-Posts.md#status-draft-scheduled-published) — a page can be a draft, scheduled for later, or live.
- **Version History** lets you roll back to an earlier saved state of the whole page (all its blocks and title) if something goes wrong — this is a full replace, so use it deliberately.

## Page-level SEO

At the bottom of each page (below the block builder), the **Page SEO & Social Metadata** panel controls that page's search-result and social-share appearance — same fields as properties and blog posts.
